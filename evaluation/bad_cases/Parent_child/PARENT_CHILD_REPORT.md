# 父子块（Parent-Child）召回评估报告

> 实验目的：验证 
>
> "小块检索、父块喂 LLM" 的父子块方案
>
> ，通过按 parent_key 去重，提升真正喂给 LLM 的父块排序。
> 同一套 31 题、同一集合 
>
> `kb_chunks`
>
> 、同一混合检索（0.9/0.1），唯一变量是 "是否按父块去重"。



***

## 一、整体指标



| 指标             | 数值         | 含义              |
| -------------- | ---------- | --------------- |
| ChildRecall@10 | 93.55%     | 正确子块进 Top10 的比例 |
| ChildMRR       | 75.92%     | 正确子块的平均倒数排名     |
| ParentRecall@5 | 93.55%     | 去重后正确父块进前 5 的比例 |
| **ParentMRR**  | **84.41%** | 去重后正确父块的平均倒数排名  |

**核心结论：去重后 MRR 从 75.92% → 84.41%（+8.5pp）。**

多个子块命中同一父块时，去重把正确父块 "顶" 到更靠前的位置 —— 这正是父子块的收益。

与平面语义块（旧）对比：



| 方案      | Recall        | MRR        |
| ------- | ------------- | ---------- |
| 平面语义块   | 96.77%        | 82.90%     |
| 父子块（去重） | 93.55%（@5 父块） | **84.41%** |

## 三、共性问题



1. **列表原子性被破坏**（q19）：安全操作类清单（换保险丝 / 电池前的步骤）被切到两个子块，正确半句落在第 11 名开外，去重也救不回 —— 这是切分层缺陷，不是去重能解决的。

2. **短句安全提示被稀释**（q35）："湿手别碰插头" 这种一两句话的提示，向量上和 "电源 / 安全" 长块高度相似，被长块挤出 Top10。



***

## 四、优化方案



| 问题    | 手段                            | 预期收益                 | 成本  |
| ----- | ----------------------------- | -------------------- | --- |
| 列表被打散 | 列表原子性切分 + 块前置章节标题             | 救回 q19，Recall +3.2pp | 低   |
| 短句被稀释 | 父子块去重已部分缓解；可对短块加权 / 单独索引      | 救回 q35               | 中   |
| 父块名额  | ParentTopP 从 5 调到 6\~7，多带一个父块 | 边缘题更稳                | 几乎无 |
