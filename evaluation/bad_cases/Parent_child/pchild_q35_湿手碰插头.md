# q35 为什么不能湿手碰 HAK180 插头？——短句安全提示被长块稀释

## 测试问题
为什么不能用湿手接触 HAK180 的电源插头？

## 预期正确结果
手册安全提示中"湿手触碰电源有触电风险"这一两句。

## 实际召回表现
- 子块检索：✗ 未命中
- 父块去重：✗ 未命中

## 根因分析
答案是**一两句话的短提示**，向量上和"电源规格 / 安全注意事项"这些长块高度相似。长块因为词更多、和 query 的重叠面更大，分数反而更高，把这句短提示挤出了 Top10。
这是"短答案被长块稀释"的典型，和之前平面切块里观察到的现象一致。

## 优化建议
1. 父子块去重已缓解一部分（短块若进 Top10，父块能被顶前）；
2. 对极短块（<50 字）单独索引或适当加权；
3. ParentTopP 从 5 提到 6~7，多带一个父块，降低边缘题漏召；
4. 重建后回归本题，目标子块进 Top10。
